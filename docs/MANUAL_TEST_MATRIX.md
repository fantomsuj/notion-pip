# macOS Windowing Manual Test Matrix

Use a development build from `dist/Perch.app`. Before each row, pin a Notion page and confirm that typing in the PiP works. Record observed behavior in **Actual Result**, then mark **Pass/Fail**.

For storage-failure cases, never damage the real Application Support store. First run the temporary-directory simulation documented in [SUPPORT.md](SUPPORT.md#safe-developer-corruption-simulation). Interactive recovery-window rows require a disposable test account or fixture build whose Application Support root contains only test data. Verify the resolved path before changing any artifact.
